# Часть 9: Создание урока и генерация предложений

## Обзор

Реализован полный цикл создания урока: от подбора слов до генерации предложений через LLM и записи в БД.

## Backend

### Эндпоинт: `POST /lesson/start`

**Вход:**
```json
{
  "word_ids": [1, 2, 3, 4, 5]
}
```

**Заголовки:**
- `Idempotency-Key`: опциональный ключ для идемпотентности

**Ответ:**
```json
{
  "lesson_id": 42,
  "lesson_number": 5,
  "exercises_total": 2,
  "current_exercise": {
    "exercise_id": 100,
    "order_index": 0,
    "sentence": "The cat runs fast.",
    "words": [
      {
        "word_id": 1,
        "lemma": "run",
        "pos": "verb",
        "surface_form": "runs",
        "is_new": false
      }
    ]
  }
}
```

### Архитектура

#### 1. Предпроверки
- Проверка онбординга (403 если не пройден)
- Проверка наличия урока `in_progress` (409 `resume_available`)
- Проверка дневного лимита (409 `limit_reached`)

#### 2. Advisory Lock
- Используется `pg_try_advisory_xact_lock(profile_id)` для защиты от параллельного старта
- Если блокировка не получена → 409 `start_in_progress`
- Блокировка автоматически снимается при завершении транзакции

#### 3. Сверка состава
- Сервер пересчитывает preview и сравнивает с присланными `word_ids`
- Если состав не совпадает → 409 `preview_outdated` с актуальным preview

#### 4. Кластеризация слов
**Алгоритм:**
- `k = ceil(N / 3)` групп
- Размеры групп отличаются не более чем на 1
- Меньшие группы идут первыми
- Распределение детерминированное от seed

**Примеры:**
- 1 → [1]
- 4 → [2, 2]
- 5 → [2, 3]
- 6 → [3, 3]
- 7 → [2, 2, 3]
- 10 → [2, 2, 3, 3]

#### 5. Контекст против повторов
- Для каждой группы берутся до 2 последних предложений с её словами
- Не более 4 предложений на группу
- Передаются в LLM как `avoid_sentences`

#### 6. Генерация через LLM
- Один запрос на все группы
- Температура: `GEN_TEMPERATURE`
- Промпт: ключ `generate_sentences`
- Языки: английский (предложение) + русский (перевод)

#### 7. Валидация ответа LLM

**Для каждой группы проверяется:**
1. Ровно одна запись на `group_index`
2. Множество `(lemma, pos)` равно запрошенному
3. `surface_form` найдена в `sentence` как целое слово (Unicode-границы)
4. Формы разных слов не пересекаются по позициям
5. `sentence` не пустая и ≤ 200 символов
6. `reference_translation` не пустая и ≤ 300 символов
7. `sentence` не содержит кириллицы
8. `reference_translation` содержит кириллицу
9. Предложение не совпадает с другими и с `avoid_sentences`

#### 8. Частичные повторы
- Валидные группы сохраняются
- Невалидные перезапрашиваются отдельным запросом
- Не более 2 повторов
- Общий дедлайн 45 секунд
- Если не удалось получить все → 503 `llm_unavailable`

#### 9. Транзакция записи

**Важно:** Транзакция открывается только после успешной генерации!

**Внутри транзакции:**
1. `SELECT ... FOR UPDATE` строки профиля
2. Повторная проверка:
   - Нет урока `in_progress`
   - Лимит не исчерпан
   - `last_lesson_number + 1` равен ожидаемому
3. Повторная проверка слов:
   - Due-слова всё ещё `active` и due
   - Для новых слов нет записи в `user_words`
4. Запись новых слов в `user_words`:
   - `status = active`
   - `stage = 0`
   - `due_lesson_number = lesson_number`
   - `source = dictionary`
5. Обновление профиля: `last_lesson_number = lesson_number`
6. Создание урока:
   - `status = in_progress`
   - `lesson_number`
   - `started_at = now UTC`
   - `started_local_date = локальная дата пользователя`
   - `words_per_lesson = N`
7. Создание `lesson_exercises`:
   - По одному на группу
   - `order_index`
   - `target_sentence`
   - `reference_translation`
   - `status = pending`
8. Создание `lesson_exercise_words`:
   - `exercise_id`
   - `word_id`
   - `surface_form`
   - `is_target = true`
   - `is_new`
   - `result = NULL`
   - `user_fragment = NULL`
   - `stage_before = NULL`
   - `stage_after = NULL`
9. Создание событий:
   - `lesson_started`
   - `new_word_accepted` для каждого нового слова

### Ключевые принципы

1. **Транзакция не держится во время LLM-запроса**
   - Все LLM-вызовы происходят до открытия транзакции
   - Транзакция открывается только для записи готовых данных

2. **Идемпотентность**
   - Повторный запрос с тем же `Idempotency-Key` возвращает существующий урок
   - Без ключа при существующем `in_progress` → 409 `resume_available`

3. **Защита от параллельного старта**
   - Advisory lock на `profile_id`
   - Клиент должен через 2 секунды запросить preview снова

4. **Ошибка LLM не тратит лимит**
   - Если генерация не удалась → 503
   - Ничего не записывается
   - Лимит не расходуется

### Коды ошибок

- **403**: `onboarding_required`, `profile_not_found`
- **409**: 
  - `resume_available` — есть незавершённый урок
  - `limit_reached` — дневной лимит исчерпан
  - `start_in_progress` — параллельный старт
  - `preview_outdated` — состав слов изменился
- **422**: ошибки валидации
- **503**: 
  - `llm_unavailable` — LLM недоступен
  - `llm_invalid_response` — невалидный ответ LLM

## Frontend

### Экран состава урока: `/lesson/preview`

**Компоненты:**

1. **Заголовок**
   - "Урок №X"
   - Градиентный фон

2. **Баннер исчерпания словаря**
   - Показывается если `dictionary_exhausted = true`
   - Текст: "Слова в словаре заканчиваются, выберите другой словарь"

3. **Секция "Повторение"**
   - Due-слова без перевода
   - Формат: `lemma (pos)`

4. **Секция "Новые слова"**
   - Новые слова с переводом
   - Кнопка "×" для отказа от слова
   - При клике вызывается `/lesson/new-word/decline`
   - Preview обновляется

5. **Кнопка "Поехали!"**
   - Блокируется во время запросов
   - Отправляет `POST /lesson/start`
   - Генерирует `Idempotency-Key`

6. **Полноэкранный лоадер**
   - Показывается во время генерации
   - Текст: "Готовим урок..."
   - Иконка книги с анимацией

7. **Обработка ошибок**
   - При ошибке LLM: "Не удалось сгенерировать предложения. Попробуйте позже."
   - При `preview_outdated`: "Состав урока изменился. Обновите страницу."
   - Кнопка "Повторить"

### Навигация

- С главной страницы кнопка "Начать урок" ведёт на `/lesson/preview`
- После успешного создания урока → `/lesson/{lesson_id}`
- При наличии `in_progress` урока → кнопка "Продолжить"

## Тесты

### Unit-тесты кластеризации
- 1 слово → [1]
- 4 слова → [2, 2]
- 5 слов → [2, 3]
- 6 слов → [3, 3]
- 7 слов → [2, 2, 3]
- 10 слов → [2, 2, 3, 3]
- Детерминированность
- Пустой список

### Unit-тесты валидации
- Валидное предложение
- Пустое предложение
- Предложение > 200 символов
- Кириллица в предложении
- Отсутствие кириллицы в переводе
- Surface form не найдена
- Дубликаты предложений

## Критерии приёмки

✅ Урок создаётся только после успешной генерации и валидации  
✅ Состав урока совпадает с фактическими словами в предложениях  
✅ Ошибка LLM не тратит лимит  
✅ Повтор с тем же `Idempotency-Key` не создаёт второй урок  
✅ Новый урок нельзя начать параллельно (advisory lock)  
✅ Экран состава урока корректно показывает due и новые слова  
✅ Кнопка "×" для отказа от нового слова работает  
✅ Транзакция не держится во время LLM-запроса  
✅ Все проверки выполняются в правильном порядке  
✅ События создаются корректно

## Пример использования

```bash
# 1. Получить preview
curl -X POST http://localhost:8000/lesson/preview \
  -H "Authorization: Bearer <token>"

# 2. Отказаться от нового слова (опционально)
curl -X POST http://localhost:8000/lesson/new-word/decline \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"word_id": 123}'

# 3. Начать урок
curl -X POST http://localhost:8000/lesson/start \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: unique-key-123" \
  -d '{"word_ids": [1, 2, 3, 4, 5]}'
```
