```
┌─────────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────────┘
                            ↑
                            │
            ┌───────────────┴───────────────┐

    │ System Prompt  │             │  User Message   │
    │                │             │                 │
    │ ИНСТРУКЦИИ:    │             │ ДАННЫЕ:         │
    │ - Роль         │             │ - Предложение   │
    │ - Правила      │             │ - Перевод       │
    │ - Формат JSON  │             │ - Целевые слова │

    └────────────────┘             └─────────────────┘
```

**Системный промпт** (хранится в БД):
- Общие инструкции для LLM
- Не меняется между запросами
- Можно редактировать через админку

**Пользовательское сообщение** (формируется в коде):
- Конкретные данные для текущего упражнения
- Меняется для каждого упражнения
- Содержит: предложение, перевод, целевые слова, перевод ученика

## Пример полного запроса к LLM

### Системный промпт:
```
Ты — преподаватель английского языка для русскоговорящих. Тебе будет 
предоставлено исходное предложение на английском языке, перевод этого 
предложения учеником на русский язык и список целевых слов. Твоя 
задача — оценить перевод ученика...

Правила оценки:
- "correct" — слово переведено точно
- "typo" — небольшая орфографическая ошибка
- "incorrect" — неправильный перевод

Верни результат в формате JSON:
{
  "evaluations": [
    {
      "lemma": "...",
      "pos": "...",
      "result": "correct|typo|incorrect",
      "user_fragment": "...",
      "feedback": "..."
    }
  ]
}
```

### Пользовательское сообщение:
```
Исходное предложение: My father went to the water park yesterday.
Эталонный перевод: Мой отец ходил в аквапарк вчера.

Целевые слова для оценки (оцени ТОЛЬКО эти слова):
- father (noun): father
- water (noun): water
- go (verb): went
- yesterday (adv): yesterday

Перевод ученика:
<<<UT_a1b2c3d4>>>мой отец ходил в водный парк вчера<<<UT_a1b2c3d4>>>

Оцени каждое целевое слово из списка выше. Предоставь ровно 4 оценок.
```

## Ответ на ваш вопрос

> из промпта не понятно как ллм узнает текст предложения, перевода и список целевых слов

**Ответ:** LLM получает эти данные из **пользовательского сообщения** (второе сообщение в запросе).

**Структура запроса:**
```python
messages = [
    {"role": "system", "content": system_prompt},      # Инструкции
    {"role": "user", "content": user_message}          # Конкретные данные
]
```

**Системный промпт** говорит LLM:
- Какую роль играть ("преподаватель английского")
- Какие правила использовать ("correct/typo/incorrect")
- В каком формате вернуть ответ ("JSON с evaluations")

**Пользовательское сообщение** говорит LLM:
- Что именно оценивать ("Исходное предложение: My father...")
- Какие слова оценивать ("Целевые слова: father, water, go, yesterday")
- Какой перевод оценить ("Перевод ученика: мой отец...")
