# Часть 12: Личный словарь пользователя

Реализована функциональность личного словаря пользователя с возможностью просмотра, фильтрации, поиска и управления статусами слов.

## Backend

### Новые эндпоинты

#### 1. GET /vocabulary/list

Получение списка слов пользователя с фильтрацией и поиском.

**Параметры:**
- `status` (опционально): фильтр по статусу (active/mastered/ignored)
- `q` (опционально): поиск по лемме или переводам (без учёта регистра)
- `page` (по умолчанию 1): номер страницы
- `page_size` (по умолчанию 20, макс 50): количество элементов на странице

**Ответ:**
```json
{
  "words": [
    {
      "word_id": 1,
      "lemma": "run",
      "pos": "verb",
      "translations": ["бегать", "бежать"],
      "status": "active",
      "stage": 2,
      "due_in_lessons": 3
    }
  ],
  "total": 150,
  "page": 1,
  "page_size": 20
}
```

**Особенности:**
- Сортировка по алфавиту леммы (без учёта регистра)
- Поиск работает по лемме и переводам (case-insensitive)
- Поле `due_in_lessons` рассчитывается как `max(due_lesson_number - last_lesson_number, 0)` для активных слов
- Для неактивных слов `due_in_lessons = 0`

#### 2. GET /vocabulary/word/{word_id}

Получение детальной информации о слове с историей контекстов.

**Ответ:**
```json
{
  "word_id": 1,
  "lemma": "run",
  "pos": "verb",
  "translations": ["бегать", "бежать"],
  "status": "active",
  "stage": 2,
  "due_in_lessons": 3,
  "context_history": [
    {
      "sentence": "The cat runs fast.",
      "surface_form": "runs",
      "result": "correct",
      "date": "2024-01-15T10:30:00Z"
    }
  ]
}
```

**Особенности:**
- Возвращает последние 20 контекстов из завершённых уроков
- Включает как целевые слова, так и подсказки (is_target=false)
- Если слово не найдено в словаре пользователя, возвращается 404

#### 3. PATCH /vocabulary/word/{word_id}/status

Изменение статуса слова.

**Запрос:**
```json
{
  "status": "ignored"
}
```

**Разрешённые переходы:**
- `active` → `ignored`: убирает из списка повторения
- `ignored` → `active`: сбрасывает stage в 0, due_lesson_number = last_lesson_number + 1
- `mastered` → `active`: сбрасывает stage в 0, due_lesson_number = last_lesson_number + 1

**Ответ:**
```json
{
  "message": "Статус изменён на 'ignored'",
  "word_id": 1,
  "new_status": "ignored"
}
```

**Особенности:**
- Идемпотентность: повторная установка того же статуса возвращает успех
- Невалидные переходы возвращают 409 `invalid_transition`
- Изменение статуса не влияет на текущий урок (если слово уже в уроке, оно будет оценено, но SRS не изменится)

### Сервисы

#### VocabularyService

- `get_vocabulary_list()` - получение списка слов с фильтрацией и поиском
- `get_word_detail()` - получение детальной информации о слове
- `change_status()` - изменение статуса слова с валидацией переходов

## Frontend

### Обновлённые страницы

#### DictionaryPage (/dictionary)

Страница личного словаря с:

**Табы:**
- Все
- Изучаю (active)
- Выучено (mastered)
- Игнор (ignored)

**Функциональность:**
- Поиск по лемме и переводам (с дебаунсом 300мс)
- Карточки слов с:
  - Леммой и частью речи
  - Переводами
  - Статусом (цветной бейдж)
  - Прогресс-баром stage/6 (для активных слов)
  - Информацией о следующем повторе
- Кнопки управления статусом:
  - "Не изучать" для активных слов
  - "Вернуть в изучение" для игнорируемых и выученных
- Пагинация (20 слов на странице)
- Клик по карточке открывает детальную страницу

#### WordDetailPage (/vocabulary/word/:wordId)

Страница детальной информации о слове:

**Содержимое:**
- Лемма и часть речи
- Все переводы
- Статус и прогресс (для активных слов)
- Информация о следующем повторе
- Кнопки изменения статуса
- История использования (последние 20 контекстов):
  - Предложение с подсветкой формы слова
  - Результат проверки (✓ Верно / ~ Опечатка / ✗ Неверно / Подсказка)
  - Дата использования

**Особенности:**
- Подсветка формы слова в предложениях (жирным шрифтом)
- Цветовая индикация результатов
- Кнопка "Назад к словарю"

## Бизнес-логика

### Поиск

Поиск работает по двум полям:
1. Лемма (case-insensitive)
2. Переводы (JSONB массив, проверка вхождения подстроки)

Используется PostgreSQL оператор `@>` для поиска в JSONB массиве переводов.

### Расчёт due_in_lessons

Для активных слов:
```typescript
due_in_lessons = max(due_lesson_number - last_lesson_number, 0)
```

Для неактивных слов:
```typescript
due_in_lessons = 0
```

### История контекстов

История формируется из таблицы `lesson_exercise_words`:
- Берутся последние 20 записей для данного слова
- Включаются как целевые слова (is_target=true), так и подсказки (is_target=false)
- Сортировка по дате оценки (evaluated_at) DESC
- Только из завершённых уроков (lesson.status = 'completed')

### Переходы статусов

**active → ignored:**
- status = ignored
- due_lesson_number = NULL
- stage не изменяется

**ignored → active:**
- status = active
- stage = 0
- due_lesson_number = last_lesson_number + 1

**mastered → active:**
- status = active
- stage = 0
- due_lesson_number = last_lesson_number + 1

Все остальные переходы возвращают ошибку 409 `invalid_transition`.

### Идемпотентность

Если текущий статус совпадает с запрошенным:
- Возвращается успех
- База данных не изменяется
- Сообщение: "Статус не изменён"

## Проверка функциональности

### Backend

```bash
# Получить список слов
curl -X GET "http://localhost:8000/vocabulary/list?page=1&page_size=20" \
  -H "Authorization: Bearer <token>"

# Фильтрация по статусу
curl -X GET "http://localhost:8000/vocabulary/list?status=active" \
  -H "Authorization: Bearer <token>"

# Поиск
curl -X GET "http://localhost:8000/vocabulary/list?q=бегать" \
  -H "Authorization: Bearer <token>"

# Получить детальную информацию
curl -X GET "http://localhost:8000/vocabulary/word/1" \
  -H "Authorization: Bearer <token>"

# Изменить статус
curl -X PATCH "http://localhost:8000/vocabulary/word/1/status" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"status": "ignored"}'
```
