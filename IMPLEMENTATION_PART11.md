# Часть 11: Возобновление урока и итоги

Реализована функциональность для возобновления незавершённых уроков, отмены уроков и просмотра итогов.

## Backend

### Новые эндпоинты

#### 1. GET /lesson/{lesson_id}/current

Получение текущего незавершённого упражнения.

**Ответ:**
```json
{
  "exercise_id": 10,
  "sentence": "The cat runs fast.",
  "order_index": 0,
  "exercises_done": 2,
  "exercises_total": 5
}
```

**Ошибки:**
- 409 `lesson_not_active` - урок завершён или отменён
- 403 `forbidden` - урок не принадлежит пользователю
- 404 `lesson_not_found` - урок не найден

#### 2. POST /lesson/{lesson_id}/abandon

Отмена урока.

**Ответ:**
```json
{
  "message": "Урок отменён"
}
```

**Поведение:**
- Урок помечается как `abandoned`
- Лимит уроков НЕ возвращается
- Обработанные слова сохраняют свои стадии SRS
- Необработанные слова остаются в прежнем состоянии
- Идемпотентен: повторный вызов возвращает успех

**Ошибки:**
- 409 `lesson_not_active` - урок уже завершён
- 403 `forbidden` - урок не принадлежит пользователю

#### 3. GET /lesson/{lesson_id}/summary

Получение итогов завершённого урока.

**Ответ:**
```json
{
  "lesson_number": 5,
  "words_total": 10,
  "reviewed": 7,
  "new_words": 3,
  "correct": 5,
  "typo": 2,
  "incorrect": 3,
  "without_errors": 7,
  "suggestions_added": 1,
  "streak": {
    "current": 2,
    "longest": 5,
    "today_done": true,
    "extended_today": true
  }
}
```

**Ошибки:**
- 409 `lesson_not_completed` - урок не завершён
- 403 `forbidden` - урок не принадлежит пользователю

### Сервисы

#### LessonResumeService

- `get_current_exercise(lesson_id)` - получение текущего упражнения
- `abandon_lesson(lesson_id)` - отмена урока

#### LessonSummaryService

- `get_summary(lesson_id)` - получение итогов урока

## Frontend

### Новые страницы

#### ResumePage (/lesson/:lessonId/resume)

Страница возобновления урока:
- Показывает прогресс (выполнено X из Y)
- Превью следующего упражнения
- Кнопка "Продолжить" - переход к упражнению
- Кнопка "Начать заново" - модальное окно подтверждения
- Автоматический переход на итоги, если урок завершён

Модальное окно подтверждения отмены:
```
Начать урок заново?

Текущий урок будет закрыт. Лимит уроков на сегодня 
уже израсходован и не вернётся. Слова, которые вы 
уже проверили, сохранят результат.

[Отмена] [Начать заново]
```

#### LessonCompletePage (/lesson/:lessonId/complete)

Страница итогов урока:
- Статистика: всего слов, точность
- Детализация: повторено, новых слов, без ошибок, добавлено подсказок
- Результаты: правильно, опечатки, ошибки
- Серия занятий: текущая и рекорд
- Анимация конфетти при продлении серии сегодня
- Кнопка "На главную"

## Бизнес-логика

### Отмена урока

1. Лимит уроков НЕ возвращается
2. Номер урока остаётся занятым
3. Обработанные слова сохраняют новые стадии SRS
4. Необработанные слова остаются в прежнем состоянии
5. Старые due-слова остаются due
6. Новые слова из словаря остаются active и попадут в следующий урок

### Итоги урока

Расчёт статистики:
- `words_total` - все целевые слова урока
- `new_words` - слова с `is_new = true`
- `reviewed = words_total - new_words`
- `without_errors = correct + typo`
- `suggestions_added` - число подсказок со `state = added`

Расчёт стрика:
- Используется функция `calculate_streak` из части 6
- `extended_today = true`, если это первый завершённый урок за сегодня
- Abandoned-уроки не участвуют в стрике

### Краевые случаи

1. **Урок через полночь:**
   - Лимит по дню старта
   - Стрик по дню завершения

2. **Урок начат несколько дней назад:**
   - Лимит списан в день старта
   - Стрик в день завершения

3. **Abandoned-уроки:**
   - Не участвуют в стрике
   - Не влияют на лимит

## Критерии приёмки

✅ Незавершённый урок можно продолжить  
✅ Можно начать заново через подтверждение  
✅ Лимит не возвращается при отмене  
✅ Обработанные слова сохраняют результаты  
✅ Итоги открываются только для завершённого урока  
✅ Конфетти появляется только если стрик продлён сегодня  
✅ Итоги открываются после перезагрузки страницы  
✅ Все тесты проходят

## Проверка функциональности

### Backend

```bash
# Получить текущее упражнение
curl -X GET http://localhost:8000/lesson/1/current \
  -H "Authorization: Bearer <token>"

# Отменить урок
curl -X POST http://localhost:8000/lesson/1/abandon \
  -H "Authorization: Bearer <token>"

# Получить итоги
curl -X GET http://localhost:8000/lesson/1/summary \
  -H "Authorization: Bearer <token>"
```

### Frontend

1. Запустить приложение: `npm run dev`
2. Создать и начать урок
3. Выйти из урока на середине
4. На главной странице нажать "Продолжить"
5. Проверить страницу возобновления
6. Нажать "Начать заново" и подтвердить
7. Проверить, что урок отменён
8. Завершить другой урок
9. Проверить страницу итогов с конфетти
