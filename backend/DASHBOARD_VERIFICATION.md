# Инструкция по проверке Части 6 — Главный экран и Dashboard

## Backend

### Запуск
```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

### Проверка эндпоинта

#### 1. Получение сводки
```bash
curl http://localhost:8000/dashboard/summary \
  -H "Authorization: Bearer <user_token>"
```

Ожидается: 200 с полной структурой:
```json
{
  "profile": {
    "level": "A2",
    "dictionary": {
      "id": 1,
      "name": "Общий словарь"
    }
  },
  "today": "2026-01-01",
  "lessons_today": 0,
  "daily_lesson_limit": 5,
  "resets_at": "2026-01-02T00:00:00Z",
  "cta": "start",
  "resume": null,
  "words": {
    "active": 0,
    "mastered": 0,
    "ignored": 0
  },
  "streak": {
    "current": 0,
    "longest": 0,
    "today_done": false
  }
}
```

#### 2. Проверка CTA состояний

**CTA = "start"**:
- Нет урока in_progress
- lessons_today < daily_lesson_limit

**CTA = "resume"**:
- Есть урок in_progress
- resume содержит lesson_id, exercises_done, exercises_total

**CTA = "limit_reached"**:
- Нет урока in_progress
- lessons_today >= daily_lesson_limit

#### 3. Проверка стрика

Стрик рассчитывается динамически на основе completed_local_date завершённых уроков.

**Тестовые случаи** (проверяются в unit-тестах):

1. **Даты пустые** → current=0, longest=0
2. **{10}, today=10** → current=1, longest=1
3. **{9}, today=10** → current=1, longest=1, под угрозой
4. **{8}, today=10** → current=0, longest=1
5. **{7,8,9,10}, today=10** → current=4, longest=4
6. **{5,6,7,9,10}, today=10** → current=2, longest=3
7. **{9,11}, today=10** → current=2, longest=2 (11 клэмпится к 10)

## Frontend

### Запуск
```bash
npm run dev
```

### Проверка

#### 1. Главная страница
После входа и онбординга пользователь попадает на главную страницу.

**Отображаемые элементы:**

1. **Приветствие**
   - Заголовок "Привет, {username}! 👋"
   - Уровень и название словаря

2. **Карточка стрика**
   - Текущая серия (число)
   - Рекорд (число)
   - Иконка огня 🔥 если серия > 0
   - Предупреждение "Позанимайтесь сегодня, чтобы сохранить серию!" если серия под угрозой

3. **Карточка уроков сегодня**
   - Прогресс: X / Y уроков начато
   - Прогресс-бар

4. **Карточка слов**
   - Изучаю (active)
   - Выучено (mastered)
   - Пропущено (ignored)

5. **Главная кнопка (CTA)**
   - **"🚀 Начать урок"** — если cta="start"
   - **"▶️ Продолжить урок"** с количеством упражнений — если cta="resume"
   - **Экран "Лимит исчерпан"** — если cta="limit_reached"

#### 2. Экран "Лимит исчерпан"
Когда lessons_today >= daily_lesson_limit и нет урока in_progress:
- Показывается иконка 🎉
- Текст "Лимит исчерпан"
- Время до обновления лимита (часы и минуты)
- Ссылка "Настройки обучения →"

#### 3. Состояние "Серия под угрозой"
Когда streak.current > 0 и today_done = false:
- Показывается предупреждение в жёлтой рамке
- Текст: "⚠️ Позанимайтесь сегодня, чтобы сохранить серию!"

### Проверка состояний

**Сценарий 1: Новый пользователь**
1. Зарегистрируйтесь и завершите онбординг
2. Перейдите на главную
3. Ожидается:
   - streak: current=0, longest=0
   - lessons_today=0
   - words: все нули
   - CTA: "Начать урок"

**Сценарий 2: После прохождения урока**
1. Пройдите урок (когда будет реализовано)
2. Вернитесь на главную
3. Ожидается:
   - lessons_today увеличится
   - streak.today_done = true
   - streak.current увеличится

**Сценарий 3: Лимит исчерпан**
1. Пройдите все доступные уроки за день
2. Вернитесь на главную
3. Ожидается:
   - CTA: "limit_reached"
   - Показывается экран с временем до сброса

## Критерии приёмки

✅ Dashboard корректно определяет CTA (start/resume/limit_reached)  
✅ Лимит считается по дню старта урока (started_local_date)  
✅ Стрик считается по дате завершения урока (completed_local_date)  
✅ Тесты на стрик проходят (все 7 тестовых случаев)  
✅ Home показывает правильные состояния кнопки  
✅ Экран "Лимит исчерпан" показывает время сброса  
✅ Стрик отображается с иконкой огня  
✅ Предупреждение показывается когда серия под угрозой  
✅ Прогресс-бар уроков за сегодня работает  
✅ Сводка слов отображается корректно
