# 📋 Структура промптов для оценки перевода

## Как работает взаимодействие с LLM

Взаимодействие с LLM состоит из **двух сообщений**:

### 1. Системный промпт (System Prompt)

**Где хранится:** `backend/app/services/prompt_service.py` и в базе данных (таблица `prompts`)

**Что содержит:** Общие инструкции для LLM — роль, правила оценки, формат ответа.

**Пример:**
```
Ты — преподаватель английского языка для русскоговорящих. Тебе будет предоставлено 
исходное предложение на английском языке, перевод этого предложения учеником на 
русский язык и список целевых слов. Твоя задача — оценить перевод ученика...

Правила оценки:
- "correct" — слово переведено точно
- "typo" — небольшая орфографическая ошибка
- "incorrect" — неправильный перевод

Верни результат в формате JSON:
{
  "evaluations": [...]
}
```

**Особенности:**
- ✅ Не меняется между запросами
- ✅ Хранится в базе данных (можно редактировать через админку)
- ✅ Задаёт общую логику работы LLM
- ❌ НЕ содержит конкретных данных для оценки

---

### 2. Пользовательское сообщение (User Message)

**Где формируется:** `backend/app/services/evaluate_translation_service.py` (метод `_call_llm`)

**Что содержит:** Конкретные данные для текущего упражнения:
- Исходное предложение на английском
- Эталонный перевод на русский
- Список целевых слов для оценки
- Перевод ученика

**Пример:**
```
Исходное предложение: My father went to the water park yesterday.
Эталонный перевод: Мой отец ходил в аквапарк вчера.

Целевые слова для оценки (оцени ТОЛЬКО эти слова):
- father (noun): father
- water (noun): water
- go (verb): went
- yesterday (adv): yesterday

Перевод ученика:
<<<UT_a1b2c3d4>>>мой отец ходил в водный парк вчера<<<UT_a1b2c3d4>>>

Оцени каждое целевое слово из списка выше. Предоставь ровно 4 оценок (одну на каждое слово).
```

**Особенности:**
- ✅ Меняется для каждого упражнения
- ✅ Содержит все конкретные данные
- ✅ Формируется динамически в коде
- ❌ Не хранится в базе данных

## Код отправки запроса

**Файл:** `backend/app/services/evaluate_translation_service.py`

```python
async def _call_llm(self, exercise, target_words, user_translation):
    # 1. Получаем системный промпт из БД
    prompt_service = PromptService(self.session)
    system_prompt = await prompt_service.get_prompt("evaluate_translation")
    
    # 2. Формируем пользовательское сообщение с конкретными данными
    words_info = []
    for tw in target_words:
        words_info.append(f"- {tw.word.lemma} ({tw.word.pos}): {tw.surface_form}")
    
    user_message = f"""Исходное предложение: {exercise.target_sentence}
Эталонный перевод: {exercise.reference_translation}

Целевые слова для оценки (оцени ТОЛЬКО эти слова):
{chr(10).join(words_info)}

Перевод ученика:
{delimiter}{user_translation}{delimiter}

Оцени каждое целевое слово из списка выше. Предоставь ровно {len(target_words)} оценок."""
    
    # 3. Объединяем в список сообщений
    messages = [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_message}
    ]
    
    # 4. Отправляем в LLM
    raw_response = await gigachat_client.chat_json_raw(
        messages=messages,
        temperature=settings.EVAL_TEMPERATURE,
        max_tokens=1000,
        timeout=10.0,
        max_retries=0
    )
```

## Зачем такое разделение?

### Преимущества

1. **Переиспользование системного промпта**
   - Один системный промпт для всех упражнений
   - Можно редактировать через админку без изменения кода
   - Не нужно передавать одни и те же инструкции каждый раз

2. **Гибкость пользовательского сообщения**
   - Конкретные данные для каждого упражнения
   - Динамическое формирование в коде
   - Легко добавить новые поля (например, контекст)

3. **Экономия токенов**
   - Системный промпт кэшируется LLM
   - Не нужно повторять длинные инструкции

4. **Удобство поддержки**
   - Изменение правил оценки → меняем только системный промпт
   - Изменение формата данных → меняем только пользовательское сообщение

## Пример полного запроса

### Системный промпт:
```
Ты — преподаватель английского языка для русскоговорящих. Тебе будет 
предоставлено исходное предложение на английском языке, перевод этого 
предложения учеником на русский язык и список целевых слов. Твоя 
задача — оценить перевод ученика, а именно: правильность перевода 
целевых слов, а так же правильность перевода других слов в предложении.

Для каждого целевого слова:
1. Найди, как ученик перевёл его в своём переводе
2. Определи, правильный ли перевод

Правила оценки:
- "correct" — слово переведено точно (допускаются синонимы и 
  грамматические варианты)
- "typo" — небольшая орфографическая ошибка, но смысл понятен
- "incorrect" — неправильный перевод или слово пропущено

ВАЖНО:
- Обязательно оцени слова из списка «Целевые слова для оценки»
- Используй ТОЧНЫЕ lemma и pos из списка (не изменяй их) - но не будь 
  строг при оценке правильности перевода (допускай синонимы и 
  грамматические формы)
- Для каждого слова — одна оценка (без дубликатов и лишних слов)
- user_fragment — точное слово (или фраза) из перевода ученика для 
  этого слова (или null, если не найдена)
- feedback — краткое объяснение, почему перевод верный/неверный

Верни результат в формате JSON:
{
  "evaluations": [
    {
      "lemma": "точная lemma из списка целевых слов",
      "pos": "точная pos из списка целевых слов",
      "result": "correct|typo|incorrect",
      "user_fragment": "фраза из перевода ученика или null",
      "feedback": "краткое объяснение"
    }
  ]
}

КРИТИЧЕСКИ ВАЖНО:
- Количество оценок ДОЛЖНО равняться количеству целевых слов
- Каждая оценка должна точно соответствовать lemma и pos целевого слова
- НЕ предлагай новые слова
- НЕ оценивай слова, которых нет в списке целевых
- Верни ТОЛЬКО валидный JSON, без markdown и пояснений
```

### Пользовательское сообщение:
```
Исходное предложение: My father went to the water park yesterday.
Эталонный перевод: Мой отец ходил в аквапарк вчера.

Целевые слова для оценки (оцени ТОЛЬКО эти слова):
- father (noun): father
- water (noun): water
- go (verb): went
- yesterday (adv): yesterday

Перевод ученика:
<<<UT_a1b2c3d4>>>мой отец ходил в водный парк вчера<<<UT_a1b2c3d4>>>

Оцени каждое целевое слово из списка выше. Предоставь ровно 4 оценок
```

## Как изменить промпт

### Вариант 1: Через админку (рекомендуется)

1. Откройте http://localhost:3000/admin/prompts
2. Найдите промпт `evaluate_translation`
3. Нажмите "Редактировать"
4. Измените текст
5. Сохраните

**Преимущества:**
- ✅ Не требует перезапуска backend
- ✅ Изменения применяются сразу
- ✅ Есть история изменений
- ✅ Можно откатить изменения

### Вариант 2: Через код

1. Измените промпт в `backend/app/services/prompt_service.py`
2. Обновите скрипт `backend/scripts/update_evaluate_prompt_v3.py`
3. Запустите скрипт: `python scripts/update_evaluate_prompt_v3.py`
4. Перезапустите backend

**Преимущества:**
- ✅ Можно версионировать в git
- ✅ Автоматическое развёртывание

## Ответ на вопрос пользователя

> из промпта не понятно как ллм узнает текст предложения, перевода и список целевых слов

**Ответ:** LLM получает эти данные из **пользовательского сообщения** (второе сообщение в запросе).

**Структура запроса:**
```python
messages = [
    {"role": "system", "content": system_prompt},      # Инструкции
    {"role": "user", "content": user_message}          # Конкретные данные
]
```

**Системный промпт** говорит LLM:
- Какую роль играть ("преподаватель английского")
- Какие правила использовать ("correct/typo/incorrect")
- В каком формате вернуть ответ ("JSON с evaluations")

**Пользовательское сообщение** говорит LLM:
- Что именно оценивать ("Исходное предложение: My father...")
- Какие слова оценивать ("Целевые слова: father, water, go, yesterday")
- Какой перевод оценить ("Перевод ученика: мой отец...")
