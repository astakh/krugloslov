# Часть 6: Главный экран и Dashboard

## Реализовано

### Backend

#### 1. Сервис стрика (`streak_service.py`)
Переиспользуемый сервис для расчёта серии занятий:
- `calculate_streak(completed_dates, today)` — вычисляет текущую и самую длинную серию
- `is_streak_at_risk(current, today_done)` — проверяет, под угрозой ли серия

Алгоритм:
1. Даты > today клэмпятся к today
2. Определяется anchor (today или yesterday)
3. Считается непрерывная цепочка от anchor
4. Находится самая длинная цепочка

#### 2. Схема Dashboard (`dashboard.py`)
Структура ответа:
- `profile` — уровень и словарь
- `today` — текущая дата в часовом поясе пользователя
- `lessons_today` — количество уроков за сегодня
- `daily_lesson_limit` — дневной лимит
- `resets_at` — время сброса лимита (полночь в часовом поясе пользователя)
- `cta` — call-to-action: "start" | "resume" | "limit_reached"
- `resume` — информация о незавершённом уроке (если есть)
- `words` — сводка слов (active, mastered, ignored)
- `streak` — серия занятий (current, longest, today_done)

#### 3. Сервис Dashboard (`dashboard_service.py`)
Собирает данные для ответа:
- Получает профиль и словарь пользователя
- Считает уроки за сегодня по `started_local_date`
- Находит урок in_progress
- Определяет CTA
- Считает слова по статусам
- Вычисляет стрик по `completed_local_date`

#### 4. Роутер Dashboard (`dashboard.py`)
Эндпоинт:
- `GET /dashboard/summary` — возвращает полную сводку

### Frontend

#### Главная страница (`HomePage.tsx`)
Отображает:
1. **Приветствие** с именем пользователя, уровнем и словарём
2. **Карточку стрика** — текущая серия, рекорд, предупреждение если под угрозой
3. **Карточку уроков** — прогресс за сегодня с прогресс-баром
4. **Карточку слов** — активные, выученные, пропущенные
5. **CTA кнопку**:
   - "🚀 Начать урок" — если можно начать
   - "▶️ Продолжить урок" — если есть незавершённый
   - Экран "Лимит исчерпан" — если лимит достигнут

Экран "Лимит исчерпан":
- Показывает время до сброса лимита
- Ссылка на настройки обучения

## Тесты

### Unit-тесты стрика
Все 7 тестовых случаев из ТЗ:
1. ✅ Даты пустые → current=0, longest=0
2. ✅ {10}, today=10 → current=1, longest=1
3. ✅ {9}, today=10 → current=1, longest=1, под угрозой
4. ✅ {8}, today=10 → current=0, longest=1
5. ✅ {7,8,9,10}, today=10 → current=4, longest=4
6. ✅ {5,6,7,9,10}, today=10 → current=2, longest=3
7. ✅ {9,11}, today=10 → current=2, longest=2

Запуск:
```bash
pytest tests/test_streak_service.py -v
```

### Интеграционные тесты
Проверяют структуру ответа и CTA логику.

Запуск:
