# Часть 7: Подбор слов для урока

## Реализовано

### Backend

#### 1. Схемы (`lesson.py`)
- `WordInfo` — базовая информация о слове (word_id, lemma, pos)
- `WordInfoWithTranslations` — слово с переводами
- `ResumeState` — состояние при наличии незавершённого урока
- `LimitReachedState` — состояние при достижении лимита
- `ReadyState` — состояние готовности к уроку
- `NoWordsState` — состояние отсутствия слов
- `DeclineWordRequest` — запрос на отказ от слова
- `DeclineWordResponse` — ответ после отказа

#### 2. Сервис подбора слов (`lesson_preview_service.py`)
Реализует полную логику подбора слов для урока:

**Шаг 1. Проверка незавершённого урока**
- Если есть урок `in_progress`, возвращает состояние `resume`
- Проверка идёт до проверки лимита

**Шаг 2. Проверка лимита**
- Считает уроки за сегодня по `started_local_date`
- Если `lessons_today >= daily_lesson_limit`, возвращает `limit_reached`
- Рассчитывает `resets_at` — ближайшая полночь в часовом поясе пользователя

**Шаг 3. Номер урока и seed**
- `next_lesson_number = last_lesson_number + 1`
- `seed = sha256(f"{profile_id}:{next_lesson_number}")`
- Используется SHA256 (не встроенный hash Python)

**Шаг 4. Ранжирование кандидатов**
- Для каждого кандидата: `rank = sha256(f"{seed}:{word_id}")`
- Сортировка по возрастанию ранга
- При исключении слова остальные сохраняют порядок

**Шаг 5. Due-слова**
- Выбираются из `user_words` с `status='active'` и `due_lesson_number <= next_lesson_number`
- Сортируются по рангу
- Берутся первые N (WORDS_PER_LESSON)

**Шаг 6. Новые слова**
- Если due-слов меньше N, берутся новые из активного словаря
- Уровень слова = уровень профиля или на один ниже
- Для A1 допускаются только A1
- В тематических словарях допускаются слова без уровня
- Исключаются слова, уже есть в `user_words` профиля
- Сортируются по рангу, берутся первые k

**Шаг 7. Итоговое состояние**
- `ready` — если есть due или новые слова
- `no_words` — если due=0 и новых=0
- `dictionary_exhausted=true` — если новых слов не хватило

#### 3. Отказ от нового слова
Метод `decline_word`:
- Проверяет онбординг (409 если не onboarded)
- Проверяет отсутствие активного урока (409)
- Проверяет наличие слова в словаре (404)
- Если слово уже `ignored` — идемпотентный успех
- Если `active` или `mastered` — 409
- Создаёт запись в `user_words` с `status='ignored'`, `source='decline'`
- Создаёт событие `new_word_declined`
- Пересчитывает preview с учётом отказа

#### 4. Роутер (`lesson.py`)
Эндпоинты:
- `POST /lesson/preview` — подбор слов без создания урока
- `POST /lesson/new-word/decline` — отказ от нового слова

## Ключевые особенности

### Детерминированность
- Seed рассчитывается как `sha256(profile_id:lesson_number)`
- Rank каждого слова: `sha256(seed:word_id)`
- Повторный вызов при том же состоянии БД возвращает тот же результат

### Приоритет проверок
1. Проверка онбординга
2. Проверка незавершённого урока (resume)
3. Проверка лимита (limit_reached)
4. Подбор слов

### Ограничения по уровням
- A1: только A1
- A2: A1 + A2
- B1: A2 + B1
- B2: B1 + B2
- C1: B2 + C1
- C2: C1 + C2
- Тематические словари: допускаются слова без уровня

### Отказ от слова
- Не создаёт урок
- Не тратит лимит
- Создаёт запись в `user_words` с `status='ignored'`
- Слово больше не предлагается как новое
- Замена — следующее по рангу слово
- Если замены нет, список может быть короче N

## Критерии приёмки

✅ Повторный preview стабилен  
✅ Отказ от нового слова заменяет его следующим  
✅ Отказанное слово больше не предлагается  
✅ Лимит и урок не затрагиваются preview  
✅ Корректная обработка состояний: resume, limit_reached, ready, no_words  
✅ due_words без переводов, new_words с переводами  
✅ Проверка онбординга, активного урока, наличия слова в словаре  
✅ Идемпотентность отказа  
✅ Событие new_word_declined создаётся  
✅ dictionary_exhausted устанавливается при нехватке слов
