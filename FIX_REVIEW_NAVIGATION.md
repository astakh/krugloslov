# ✅ Исправлена проблема с переходом на промежуточную страницу после разбора результатов

## Проблема

После нажатия кнопки "Следующее упражнение" на странице разбора результатов (ReviewPage) происходил переход на промежуточную страницу ResumePage с сообщением "Есть незавершённый урок", вместо прямого перехода на следующее упражнение.

## Корневая причина

В ReviewPage при нажатии "Далее" происходил переход на `/lesson/${lessonId}`:

```typescript
const handleNext = () => {
  if (result?.lesson_completed) {
    navigate(`/lesson/${lessonId}/complete`);
  } else {
    // Navigate to next exercise
    // TODO: Get next exercise ID from backend
    navigate(`/lesson/${lessonId}`);  // ❌ Неправильно!
  }
};
```

Этот URL попадал на LessonPage, который запрашивал `/lesson/${lessonId}/current` и перенаправлял на текущее упражнение. Но из-за того, что урок оставался в статусе "in_progress", происходило перенаправление на ResumePage вместо прямого перехода на ExercisePage.

## Решение

Изменён метод `handleNext` в ReviewPage, чтобы он напрямую получал ID следующего упражнения и переходил на него:

```typescript
const handleNext = async () => {
  if (result?.lesson_completed) {
    navigate(`/lesson/${lessonId}/complete`);
  } else {
    // Get next exercise and navigate directly to it
    try {
      const current = await apiClient.get<{
        exercise_id: number;
        sentence: string;
        order_index: number;
        exercises_done: number;
        exercises_total: number;
      }>(`/lesson/${lessonId}/current`);
      
      navigate(`/lesson/${lessonId}/exercise/${current.exercise_id}`);  // ✅ Правильно!
    } catch (err) {
      const error = err as any;
      
      // If lesson is completed, redirect to summary
      if (error?.error?.code === "lesson_not_active") {
        navigate(`/lesson/${lessonId}/summary`);
        return;
      }
      
      // For other errors, redirect to home
      navigate('/');
    }
  }
};
```

## Как это работает теперь

### Поток навигации

```
1. Пользователь завершает упражнение на ExercisePage
   ↓
2. Переход на ReviewPage для разбора результатов
   ↓
3. Пользователь нажимает "Далее"
   ↓
4. ReviewPage запрашивает GET /lesson/${lessonId}/current
   ↓
5. Backend возвращает ID следующего упражнения
   ↓
6. ReviewPage перенаправляет на /lesson/${lessonId}/exercise/${nextExerciseId}
   ↓
7. ExercisePage загружает следующее упражнение ✅
```

### Обработка ошибок

- Если урок завершён (все упражнения выполнены), происходит переход на страницу итогов (`/lesson/${lessonId}/summary`)
- Если произошла другая ошибка, происходит переход на главную страницу
