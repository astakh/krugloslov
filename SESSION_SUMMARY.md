## 🔧 Технические решения

### Архитектура
- **Backend:** FastAPI + SQLAlchemy 2.0 + PostgreSQL
- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS
- **LLM:** GigaChat API с двухуровневой архитектурой
- **Аутентификация:** JWT с ротацией refresh tokens

### Безопасность
- Хеширование паролей (bcrypt)
- Маскирование чувствительных данных
- Безопасная подстановка SQL идентификаторов
- Валидация всех входных данных
- Rate limiting
- Логирование действий

### Производительность
- Асинхронные операции
- Приблизительный подсчёт строк (pg_class.reltuples)
- Пагинация везде где нужно
- Оптимизированные SQL запросы
